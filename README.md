## 🧭 What Ext4 Does

Linux computers often use file systems called ext2, ext3, and ext4. Windows does not normally open these drives. Ext4 adds that ability to Windows. It works as a native driver, which means it is made to work directly with Windows storage features rather than through a separate Linux machine or a virtual machine.

With Ext4, you can connect a Linux drive and view its folders in a familiar Windows-style way. You can open documents, copy photos, move music files, and save changes back to the Linux drive. The application is built for read and write access, so it is not limited to viewing files only.

Ext4 also includes support for advanced Linux storage layouts. That includes encrypted Linux volumes through LUKS1 and LUKS2, plus LVM discovery for drives that are grouped together in flexible ways. These features matter when a Linux drive is not a simple single partition. Ext4 is designed to find and work with those layouts so you can reach your files.

Ext4 includes several features that make Linux drive access more reliable and more complete.

- **ext2, ext3, and ext4 support:** Open and work with the three main Linux file-system versions.
- **Read and write access:** Browse files, copy them to Windows, and save changes back to the Linux drive.
- **Journal support through jbd2:** Helps the file system keep track of changes and recover more reliably after unexpected shutdowns.

- **Linux verification:** Checks behavior against Linux file-system expectations.
- **Deterministic unload:** Removes the driver cleanly when you stop using it.
- **Windows 10 and Windows 11 x64 support:** Designed for modern 64-bit Windows computers.
